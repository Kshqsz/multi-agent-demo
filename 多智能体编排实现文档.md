# 多智能体编排 + Skill 优化 —— 实现文档

## 项目概览

通过三个阶段构建一个可被 Skill 持续优化的多智能体编排系统：

1. **阶段一**：跑通最小多智能体系统
2. **阶段二**：让系统可观测（结构化日志）
3. **阶段三**：编写 Skill 实现自动优化

示范场景：**研究报告生成器**（用户输入问题 → 多 Agent 协作 → 输出报告）

### 1.3 编写 agents.yaml

所有 Agent 的角色、prompt、工具权限都在这里定义。Skill 后续直接修改此文件来优化 Agent。

```yaml
# agents.yaml
model: DeepSeek-V4-Flash

agents:
  planner:
    description: "任务规划者，把用户问题拆解为子任务列表"
    system_prompt: |
      你是一个任务规划专家。
      接收用户的问题后，将其拆解为 2-4 个具体的研究子任务。
      输出格式为 JSON 数组，例如：
      ["子任务1", "子任务2", "子任务3"]
      只输出 JSON，不要其他内容。
    temperature: 0.3

  researcher:
    description: "研究者，针对单个子任务进行深入分析"
    system_prompt: |
      你是一个专业研究员。
      针对给定的子任务，提供详细、准确的分析和信息。
      输出结构化的研究结果，包含关键发现和要点。
    temperature: 0.5

  writer:
    description: "撰写者，把所有研究结果整合为完整报告"
    system_prompt: |
      你是一个专业报告撰写者。
      将多个研究结果整合为一篇结构清晰、逻辑连贯的报告。
      报告应包含：摘要、主要发现、结论三个部分。
    temperature: 0.7

  reviewer:
    description: "评审者，对最终报告打分并提供改进建议"
    system_prompt: |
      你是一个严格的质量评审专家。
      对报告从以下维度打分（1-10分）：
      1. 准确性
      2. 完整性
      3. 可读性
      输出 JSON 格式：{"accuracy": 8, "completeness": 7, "readability": 9, "suggestions": ["建议1", "建议2"]}
      只输出 JSON，不要其他内容。
    temperature: 0.2
```

### 1.4 编写 orchestrator.py

```python
# orchestrator.py
import json
import os
import time
import yaml
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()
client = OpenAI(
    api_key=os.environ.get("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com",
)


def load_config():
    with open("agents.yaml", "r", encoding="utf-8") as f:
        return yaml.safe_load(f)


def call_agent(agent_name: str, agent_config: dict, user_message: str, model: str) -> dict:
    """调用单个 Agent 并返回结果"""
    start_time = time.time()

    response = client.chat.completions.create(
        model=model,
        max_tokens=2048,
        messages=[
            {"role": "system", "content": agent_config["system_prompt"]},
            {"role": "user", "content": user_message},
        ],
        temperature=agent_config.get("temperature", 0.5),
    )

    elapsed = round(time.time() - start_time, 2)
    output = response.choices[0].message.content

    return {
        "agent": agent_name,
        "input": user_message,
        "output": output,
        "elapsed_seconds": elapsed,
        "input_tokens": response.usage.prompt_tokens,
        "output_tokens": response.usage.completion_tokens,
    }


def run_pipeline(question: str) -> dict:
    """执行完整的多智能体流水线"""
    config = load_config()
    agents = config["agents"]
    model = config["model"]
    trace = []  # 记录每一步的执行情况

    print(f"\n问题：{question}\n{'='*50}")

    # Step 1: Planner 拆解任务
    print("[1/4] Planner 拆解任务...")
    plan_result = call_agent("planner", agents["planner"], question, model)
    trace.append(plan_result)

    try:
        subtasks = json.loads(plan_result["output"])
    except json.JSONDecodeError:
        subtasks = [question]  # 解析失败则直接用原问题

    print(f"  拆解为 {len(subtasks)} 个子任务：{subtasks}")

    # Step 2: Researcher 并行研究每个子任务
    print("[2/4] Researcher 研究各子任务...")
    research_results = []
    for i, subtask in enumerate(subtasks):
        print(f"  研究子任务 {i+1}/{len(subtasks)}: {subtask}")
        result = call_agent("researcher", agents["researcher"], subtask, model)
        trace.append(result)
        research_results.append(result["output"])

    # Step 3: Writer 整合报告
    print("[3/4] Writer 整合报告...")
    combined_research = "\n\n---\n\n".join(
        [f"子任务：{subtasks[i]}\n\n{r}" for i, r in enumerate(research_results)]
    )
    writer_input = f"原始问题：{question}\n\n研究结果：\n{combined_research}"
    writer_result = call_agent("writer", agents["writer"], writer_input, model)
    trace.append(writer_result)

    # Step 4: Reviewer 评审报告
    print("[4/4] Reviewer 评审报告...")
    reviewer_result = call_agent(
        "reviewer", agents["reviewer"], writer_result["output"], model
    )
    trace.append(reviewer_result)

    try:
        scores = json.loads(reviewer_result["output"])
    except json.JSONDecodeError:
        scores = {"error": "解析评分失败"}

    return {
        "question": question,
        "report": writer_result["output"],
        "scores": scores,
        "trace": trace,
    }
```

### 1.5 编写 run.py

```python
# run.py
import json
import os
from datetime import datetime
from orchestrator import run_pipeline


def main():
    question = input("请输入研究问题：").strip()
    if not question:
        question = "量子计算对密码学的影响是什么？"

    result = run_pipeline(question)

    # 打印报告
    print(f"\n{'='*50}")
    print("最终报告：")
    print(result["report"])
    print(f"\n评分：{result['scores']}")

    # 保存日志
    os.makedirs("logs", exist_ok=True)
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_path = f"logs/run_{timestamp}.json"
    with open(log_path, "w", encoding="utf-8") as f:
        json.dump(result, f, ensure_ascii=False, indent=2)

    print(f"\n日志已保存：{log_path}")


if __name__ == "__main__":
    main()
```

**运行验证**

```bash
python run.py
```

预期：看到4个 Agent 依次执行，最终输出报告 + 评分 + 保存日志文件。

### 2.3 添加汇总统计脚本

新建 `stats.py`，用于快速查看多次运行的统计数据（供 Skill 读取）：

```python
# stats.py
import json
import os
import glob


def analyze_logs():
    log_files = glob.glob("logs/run_*.json")
    if not log_files:
        print("暂无日志")
        return

    all_runs = []
    for f in sorted(log_files):
        with open(f, encoding="utf-8") as fp:
            all_runs.append(json.load(fp))

    print(f"总运行次数：{len(all_runs)}\n")

    # 各 Agent 平均耗时
    agent_times = {}
    agent_scores = {"accuracy": [], "completeness": [], "readability": []}

    for run in all_runs:
        for step in run["trace"]:
            name = step["agent"]
            agent_times.setdefault(name, []).append(step["elapsed_seconds"])

        scores = run.get("scores", {})
        for key in agent_scores:
            if key in scores:
                agent_scores[key].append(scores[key])

    print("各 Agent 平均耗时（秒）：")
    for agent, times in agent_times.items():
        avg = sum(times) / len(times)
        print(f"  {agent}: {avg:.2f}s")

    print("\n平均评分：")
    for key, vals in agent_scores.items():
        if vals:
            avg = sum(vals) / len(vals)
            print(f"  {key}: {avg:.1f}/10")


if __name__ == "__main__":
    analyze_logs()
```

## 阶段三：编写 Skill 实现自动优化

### 3.1 Skill 存放位置

技能文件放在 DeepSeek 的 skills 目录：

```
.deepseek/skills/
├── review-orchestration.md
├── optimize-agent.md
└── add-agent.md
```

### 3.2 Skill 1：review-orchestration

**文件**：`.deepseek/skills/review-orchestration.md`

**作用**：分析日志，找出瓶颈，提出改进方案

```markdown
Read the latest log file in `logs/` directory and the `agents.yaml` file in the current project.

Analyze the multi-agent orchestration run and provide:

1. **Performance bottlenecks**: Which agent took the longest? Any token waste?
2. **Quality issues**: What did the reviewer suggest? Are scores below 7?
3. **Routing problems**: Did the planner create good subtasks? Were any redundant?
4. **Concrete improvements**: List 3 specific changes to `agents.yaml` that would improve performance or quality.

Be specific—reference actual values from the logs (e.g., "researcher took 8.2s on average").
End with: "Run `/optimize-agent <agent-name>` to apply improvements to a specific agent."
```

**使用方式**：在项目目录下运行 `/review-orchestration`

---

### 3.3 Skill 2：optimize-agent

**文件**：`.deepseek/skills/optimize-agent.md`

**作用**：针对指定 Agent 重写 system_prompt

```markdown
The user wants to optimize a specific agent in `agents.yaml`.

Arguments: $ARGUMENTS (the agent name, e.g., "researcher" or "writer")

Steps:
1. Read `agents.yaml` to understand the current agent configuration
2. Read the latest 3 log files in `logs/` to see this agent's actual inputs/outputs
3. Identify weaknesses: vague outputs, high token usage, low reviewer scores, slow responses
4. Rewrite the agent's `system_prompt` in `agents.yaml` to fix these issues:
   - Make instructions more specific and structured
   - Add output format constraints if outputs were inconsistent
   - Reduce verbosity if token usage was high
5. Show the diff between old and new prompt
6. Ask the user to confirm before saving

After saving, suggest: "Run `python run.py` to test the optimized agent."
```

**使用方式**：`/optimize-agent researcher`

---

### 3.4 Skill 3：add-agent

**文件**：`.deepseek/skills/add-agent.md`

**作用**：在系统中脚手架一个新 Agent

```markdown
The user wants to add a new agent to the multi-agent orchestration system.

Arguments: $ARGUMENTS (description of the new agent's role)

Steps:
1. Read `agents.yaml` to understand the current pipeline
2. Read `orchestrator.py` to understand how agents are called
3. Design the new agent:
   - Choose a short snake_case name
   - Write a focused system_prompt (under 150 words)
   - Set appropriate temperature (0.2 for structured output, 0.7 for creative)
4. Add the new agent to `agents.yaml`
5. Determine where in the pipeline it should run (before writer? after reviewer?)
6. Update `orchestrator.py` to call the new agent at the right step
7. Show all changes and ask for confirmation before saving

Common agent types to suggest if role is unclear:
- `fact_checker`: verifies claims in research results
- `summarizer`: creates concise summaries of long research
- `critic`: provides adversarial perspective on conclusions
```

**使用方式**：`/add-agent 事实核查者，验证研究结果中的关键声明`

### 3.5 优化工作流

```
1. python run.py          # 运行系统，产生日志
2. /review-orchestration  # 分析日志，找瓶颈
3. /optimize-agent writer  # 优化某个 Agent 的 prompt
4. python run.py          # 再次运行，对比评分
5. python stats.py        # 查看统计数据，确认改善
6. 重复 1-5
```

### 文件职责速查

| 文件 | 职责 | 谁来修改 |
|------|------|---------|
| `agents.yaml` | Agent 角色和 prompt 定义 | Skill 自动修改 |
| `orchestrator.py` | 调度逻辑和流水线顺序 | Skill 或手动 |
| `run.py` | 入口，保存日志 | 很少改动 |
| `stats.py` | 日志统计分析 | 只读 |
| `logs/*.json` | 运行记录 | 系统自动生成 |

### Skill 速查

| Skill | 触发场景 |
|-------|---------|
| `/review-orchestration` | 运行后想知道哪里需要改进 |
| `/optimize-agent <名称>` | 某个 Agent 输出质量差或速度慢 |
| `/add-agent <描述>` | 想给流水线增加新能力 |
